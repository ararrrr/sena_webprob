# MongoDB Atlas + Vercel Integration Guide

## Quick Setup (5 minutes)

### 1. Create Free Cluster
- [ ] Go to https://cloud.mongodb.com → Create account
- [ ] **+ Create** → New Deployment
- [ ] **Provider**: AWS | **Region**: Closest to you
- [ ] **Tier**: M0 Sandbox (free forever)
- [ ] Click **Create**

### 2. Add Database User
1. **Database Access** → **Add New Database User**
   - **Username**: `vercel_user`
   - **Password**: Click **Generate Secure Password** (copy it)
   - **Role**: `readWriteAnyDatabase`
   - Click **Add User**

### 3. Allow Vercel IPs (CRITICAL)
1. **Network Access** → **Add IP Address**
2. Click **Allow Access from Anywhere**: `0.0.0.0/0`
3. Click **Confirm**

### 4. Get Connection String
1. **Clusters** → **Connect**
2. Select **Drivers**
3. Copy the connection string (looks like):
   ```
   mongodb+srv://vercel_user:<password>@cluster0.xxx.mongodb.net/?retryWrites=true&w=majority
   ```

### 5. Customize Connection String
Replace:
- `<password>` → Your actual password from step 2
- Append database name: `/databaseName?...`

Final format:
```
mongodb+srv://vercel_user:MySecurePassword@cluster0.abc123.mongodb.net/senaDB?retryWrites=true&w=majority
```

### 6. Store Securely
- **Vercel**: Add as `MONGO_URI` environment variable
- **Local Dev**: Add to `sena-server/.env` (never commit)
- **Never share or commit this string**

## Troubleshooting MongoDB Connection

### Error: "connect ETIMEDOUT"
- [ ] Verify `0.0.0.0/0` is whitelisted in Network Access
- [ ] Test connection string is correct (no extra spaces)
- [ ] Check password has special characters properly escaped

### Error: "Authentication failed"
- [ ] Verify username and password in connection string
- [ ] Check password in MongoDB matches what you're using
- [ ] If password has `@` or `#`, URL-encode it

### Error: "Database not found"
- [ ] Vercel: Check MONGO_URI includes database name
- [ ] Local: Check `.env` file has complete connection string

## Security Notes

⚠️ **0.0.0.0/0 means "allow from anywhere"** — acceptable because:
- Database requires valid credentials (strong password)
- Vercel's IP range is unpredictable
- Use MongoDB Atlas user permissions for additional control

✅ **Best practice**: Use strong password (auto-generated by MongoDB Atlas)
